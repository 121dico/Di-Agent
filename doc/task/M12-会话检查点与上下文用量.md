# M12 会话检查点与上下文用量

## 目标

让用户能够看见每个 Agent 在当前 Conversation 中的上下文用量，并把长任务压缩为可查询、可预览、可迁移到新 CLI Session 的 Conversation Checkpoint。

## 已实现

- [x] `conversation_checkpoints`：版本、来源消息范围、来源 Agent/Session、scope、结构化摘要、Markdown 和生命周期状态。
- [x] `agent_sessions`：按 Conversation + Agent 隔离的 Session 代次、Token 用量、窗口容量和阈值状态。
- [x] 选中 Agent 异步生成摘要，daemon 不可用或返回无效 JSON 时保留确定性 fallback。
- [x] Checkpoint 列表、详情、创建、删除和继续到新 Session API。
- [x] 续接权限校验：会话成员、Agent 绑定、私有/共享 scope。
- [x] daemon fresh-session 协议和 `agent_id + conversation_id` persistent slot 隔离。
- [x] 聊天头部上下文入口、Agent 切换、用量进度、检查点预览和续接操作。
- [x] 估算值明确标记为“估算”，保留未来 `actual` usage 数据源。

## 阈值

| 状态 | 比例 |
|------|------|
| `normal` | `< 70%` |
| `warning` | `>= 70%` |
| `critical` | `>= 85%` |

首版只提示和允许用户手动迁移，不静默自动切换 Session。
