# V1.2 指标概览与快照净增

## 口径

V1 从 `epower_platform.price_sensitive` 对每个 dt 的 `price_sensitivity_score IS NOT NULL` 用户执行 DUID 去重计数，结果保存在 `report_daily_analytics`。2026-08-11、09-09、09-10 的已赋分人数分别为 7,841,704、8,334,214、8,333,105；09-10 全量人数为 42,535,220。

- 当前价敏用户：末日已赋分人数。
- 累计净增：末日减区间首日，491,401。
- 最近一天：末日减前日，-1,109；增长率为该差值除以前日人数，约 -0.0133%。
- 日均净增：完整31日快照形成30个日对，491,401 / 30，显示16,380。
- 覆盖率：8,333,105 / 42,535,220，约19.59%。

V1.2 对应已有 `calculated_user_count`（ps_score 非空，含 PRIOR），沿用当前源表 dt + duid 唯一的计数契约，不代表已完成全量去重验证，也不等于 ps_conf > 0 人群。新增组件不改变上游查询或存储，不将 V1 数值复制给 V1.2。

## 实现

从已加载的当前时间/城市范围每日快照重新计算增量，忽略单日缓存中的零增量字段。完整日期横轴缺失留空；前一日缺失不计算单日增量；日均只平均连续有效日对，并展示分母；累计相对首个有效快照。单日没有可计算日增量，显示横线。前日人数为0时增长率不可用。

V1.2 六项概览、每日净增柱、累计及增长率曲线沿用现有样式，原始负值保留，不拟合抹平。有订单人群和原有分布/趋势、待接入的真实订单日指标仍独立。全量人数保留在概览说明中。
