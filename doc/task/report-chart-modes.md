# V1.2 趋势 / 真实数值双模式

## 范围
每日人群规模、全量每日价敏分布、有订单每日价敏分布，共用展示切换，默认「趋势对比」。不改接口与数据库，也不触发重新查询。

## 口径
- 用户纠正不希望首尾归一重合，趋势坐标改为 (值 − 本曲线所选区间均值) / 本曲线总体标准差；不固定起点、终点或极值，不随机错位。
- 趋势隐藏纵轴数字，曲线高低不是人数、不是百分比增长；不能用不同曲线高度比较增长率。真正同比例的曲线仍可重合，不伪造差异。
- 恒定序列放 0，单点不造曲线，缺失/失败日期断开不补零。
- 提示保留真实人数；相邻日变化率 = (当日 − 前日) / |前日| × 100%。首日、前日缺失或为零时说明不可计算。
- 真实模式保留已有统一人数坐标，图例显隐状态切换时不丢失。

## 验收
组件测试覆盖大/小体量独立缩放、真实提示、日变化率、常量、缺失、单点、三图切换及图例状态。追加边界回归验证真实→趋势→真实的原始坐标恢复，以及 -50% / -100% 下降。

标准审查 0 阻塞问题，需求审查 0 问题；小于 0.005% 的真实日变化率会因两位小数显示为 ±0.00%，不影响人数或曲线。

仅部署前端，无后台重启、无数据库变更。可恢复前端备份：`/root/deploy-backups/report-chart-modes-H8Y0OR/previous`。

## 离群点（用户追加）
统一覆盖报表折线及柱图的曲线叠层。相邻前后日期必须真实连续且点值有限，只有明显跳出后回归的孤立点才作为候选；阈值取相邻基准绝对值的 3%、局部 MAD×1.4826×3、邻点差×3、数值容差四者最大值。不从首尾或缺失日推断异常，不自动删除持续新水平。

候选点保留原始值、日期、真实日变化率，空心点单独标记，主线在当日断开，不插值/不强行平滑。趋势均值/标准差不计候选，超出图框的标记仅边缘定位并显示说明。真实模式（包括柱图）保留原始值确定坐标范围，不裁切真实量级。异常点或前日涉及异常时，变化率仍真实计算但附提示。

该规则只提示统计上的疑似离群，不能证明上游 API 或源表错误；需业务核查。未改变源数据或已保存统计。
