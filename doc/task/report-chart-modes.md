# V1.2 趋势 / 真实数值双模式

## 范围
每日人群规模、全量每日价敏分布、有订单每日价敏分布，共用展示切换，默认「趋势对比」。不改接口与数据库，也不触发重新查询。

## 口径
- 趋势坐标 = (值 − 本曲线所选区间最小值) / (最大值 − 最小值) × 100。
- 纵轴表示各自区间位置，不是人数、不是百分比增长；不能用不同曲线高度比较增长率。
- 恒定序列放 50，单点不造曲线，缺失/失败日期断开不补零。
- 提示保留真实人数；相邻日变化率 = (当日 − 前日) / |前日| × 100%。首日、前日缺失或为零时说明不可计算。
- 真实模式保留已有统一人数坐标，图例显隐状态切换时不丢失。

## 验收
组件测试覆盖大/小体量独立缩放、真实提示、日变化率、常量、缺失、单点、三图切换及图例状态。真实页面验收记录待补。
