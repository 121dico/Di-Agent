# 图表查询与结果对应记录

## 已确认范围

只保存报表聚合结果、真实查询过程和图表映射，不同步全量用户明细，不新增明细仓库。
先覆盖现有 price_sensitive_v1_2 固定报表。每张图有稳定标识，对应查询键、结果字段和公式；
执行时保存映射版本、请求参数、真实上游 SQL（如有）、查询 ID、时间、状态与聚合结果。
历史未记录的 SQL 不补造。缓存命中不触发新查询。失败和截断结果不得冒充完整统计。

## UI Brief（myuiskill 默认模式）

- 管理员：报表 → 图表数据逻辑 → 选择图表 → 选择执行记录 → 展开请求/SQL/结果。
- 普通用户：不展示入口，后端同样拒绝访问。
- 沿用浅色报表、Ant Design Drawer/Button 与现有语义颜色；选择器用原生 select，避免抽屉弹层兼容问题；不改图表布局。
- 请求、SQL、字段映射默认折叠；结果表可横向滚动；小屏抽屉不超视口。
- loading、空历史、未知 SQL、请求失败、重跑中分别显示；关闭/切换报表后旧请求不能覆盖新状态。
- 重跑沿用当前数据源权限与字段契约，保存独立核验结果，不暗中修改公开图表。
- 不开放任意 SQL 执行和用户明细下载。管理员仍通过已有报表编辑入口修改配置。
- 自动选择沿用现有主题与抽屉，不单独搭视觉原型；0–7 auto-approved；8–9 已通过测试及线上真实页面验证。

## 验收

API 服务边界覆盖管理员权限、真实 SQL 采集、失败/截断与重跑校验。
组件边界覆盖图表对应关系、历史映射、空态和结果数值。
真实页面选择一张图、查看参数与结果、重跑并刷新确认记录保留。

## 存储与接口

- PostgreSQL `report_query_executions`：迁移 `084_report_query_provenance.sql`；不可变执行快照，保存聚合行、请求、上游 SQL、查询 ID、日期/城市、状态及执行时图表映射版本。
- `GET /api/reports/:id/provenance`：管理员查询；可用重复 `execution_id` 参数取回当前缓存关联的历史执行。
- `POST /api/reports/:id/provenance/replay`：仅接受已存的 `execution_id`；重新校验数据源契约及聚合查询，追加核验结果，不执行任意 SQL，不替换公开缓存。
- 图表通过稳定 `chart_key` 与查询键关联；缓存携带 `execution_ids`。环图限定展示快照日期，趋势图限定日期范围；历史回看使用执行时公式及映射。
- 首批范围仅现有 V1.2 固定报表。旧缓存没有执行 ID 时如实显示缺少对应记录，不补造 SQL，不假定新查询就是历史来源。
