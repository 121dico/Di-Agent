# 图表查询与结果对应记录

## 已确认范围

只保存报表聚合结果、真实查询过程和图表映射，不同步全量用户明细，不新增明细仓库。
先覆盖现有 price_sensitive_v1_2 固定报表。每张图有稳定标识，对应查询键、结果字段和公式；
执行时保存映射版本、请求参数、真实上游 SQL（如有）、查询 ID、时间、状态与聚合结果。
历史未记录的 SQL 不补造。缓存命中不触发新查询。失败和截断结果不得冒充完整统计。

## UI Brief（myuiskill 默认模式）

- 管理员：报表 → 图表数据逻辑 → 选择图表 → 选择执行记录 → 展开请求/SQL/结果。
- 普通用户：不展示入口，后端同样拒绝访问。
- 沿用浅色报表、Ant Design Drawer/Select/Button 与现有语义颜色；不改图表布局。
- 请求、SQL、字段映射默认折叠；结果表可横向滚动；小屏抽屉不超视口。
- loading、空历史、未知 SQL、请求失败、重跑中分别显示；关闭/切换报表后旧请求不能覆盖新状态。
- 重跑沿用当前数据源权限与字段契约，保存独立核验结果，不暗中修改公开图表。
- 不开放任意 SQL 执行和用户明细下载。管理员仍通过已有报表编辑入口修改配置。
- 自动选择沿用现有主题与抽屉，不单独搭视觉原型；0–7 auto-approved，8–9 待测试与真实页面验证。

## 验收

API 服务边界覆盖管理员权限、真实 SQL 采集、失败/截断与重跑校验。
组件边界覆盖图表对应关系、历史映射、空态和结果数值。
真实页面选择一张图、查看参数与结果、重跑并刷新确认记录保留。
