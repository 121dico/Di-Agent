# 订单人群人数与同等级占比柱图

## 需求与口径
在订单笔数筛选区域新增人数、占同等级总人数两张柱状图，横轴为价敏等级，支持等级多选、全选/全取消。
复用已加载的所选笔数组和全部有订单人群，不新增请求。比例为所选笔数组该等级人数 / 全部有订单人群该等级人数，分母不因等级显隐变化。
原环图、表格、日期/城市/笔数筛选保持不变；人数不是订单笔数。

## UI（myuiskill 默认模式）
已自动选择并排柱图、七档多选。分别使用人数刻度与0–100%刻度，沿用浅色主题及等级颜色；支持悬停/焦点/点击读数。
小屏上下排列；未知或0分母显示不可用而非0%；全取消可一键恢复。
