# 模板一与 V1.2 报表

## 范围

将归档式模板升级为管理员可一键套用的运行时模板，创建独立 V1.2 报表，保持旧报表与已确认样式。

## 已验证

- 前后端构建通过，报表服务专项测试通过；前端报表模型测试通过。
- 覆盖管理员权限、重复套用不覆盖、字段停用拒绝、快照日期时区、缺失日期、空分、加权均分及聚合缓存。
- 真实 API 普通聚合可返回；全量 COUNT DISTINCT 查询触发上游 8 GiB 内存限额，禁止改用 COUNT 冒充去重结果。
- 管理员在生产页面「套用模板」创建独立 V1.2 实例，重复套用后数据库仍只有一个实例，旧报表保留。
- 页面选择北京市、近1天，真实聚合成功；点击「立即生成」产生 succeeded 运行记录，再读取显示聚合缓存。已视觉检查指标面板、七档颜色环图、单日基准点，并验证曲线及环图图例显隐。
- 未登录请求模板目录返回401；普通用户禁止管理的服务层测试通过。
- 两轮代码审查已修复筛选遗失、定时扫描31天、空分拟合污染、缺失日期跨日增量及静默接受截断聚合的问题；复核无 critical。

## 待验收与已知限制

- 全量统计需要上游预聚合或有界分批方案，当前不得宣称全量曲线已生成。
- 七天查询也可能触发上游30秒估算时限。自动全量生成尚未验收通过；默认每日只请求最新一天，但单日全量仍可能超资源。
- 1年等大范围超过1000个聚合分组会明确拒绝，尚未实现全历史分块读取。
- 完整后端测试中已有部署路径隔离测试 `TestServeSite_RejectsTraversalIntoAnotherDeployment` 失败（404/403）；本次未改动该模块。

接口、缓存与业务口径见 [模板接口设计](../design/api-report-templates.md)。
