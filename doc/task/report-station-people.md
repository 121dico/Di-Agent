# 数据验证：用户复购与人群重合

状态：2026-09-14 已部署；自动测试通过，真实产品路径与视口验收尚未完成。

## 已确认需求

用户要求验证宏观等级人数背后是否为同一批消费用户，以及重复消费用户的价敏等级。
在 V1.2 数据验证附区增加用户级统计；来源仍为 station_price_sensitive_test_detail。

## 统计与接口

- GET `/api/reports/:id/station-people?station=ALL&start=YYYY-MM-DD&end=YYYY-MM-DD`。
- refresh=true 仅管理员；普通用户只能查看汇总。不改变数据源与报表管理权限。
- 同原验证区过滤 duid>0、MATCHED、private（含会员，private 不代表已核验私家车）。
- 按 dt/station_id/duid/ps_level 分组并 COUNT_DISTINCT(order_id)。表契约为同一 dt 内 order_id 唯一。
- DUID 保持整数字符串精度，仅后端内存处理，不返回或保存到缓存。
- 区间统计：跨日去重用户、至少2笔、至少2天、ALL下至少2站，按区间最后一次消费等级拆分1/2/3+笔和跨日/跨站。
- 每日统计：当日等级，历史内首次出现/此前消费过、前一日/前7个日历日重合；前7天同等级重合独立计数，标签变化不冒充新人。
- 历史依据接口最早可用日期至区间末日，同一场站和同一人群口径；不声称平台新客或完整留存率。缺失日期不补零。
- 先按全部已知历史拉取用户日聚合，再按所选区间统计；最多50万组，每页5000，完整分页去重/总数校验，超限失败不返回部分结论。
- 使用现有 PostgreSQL analytics cache，独立 station-people 键，配置/基础快照时间/范围进入键；下一个北京时间10点后请求触发更新，非后台预热。
