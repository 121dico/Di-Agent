# 城市与订单档位预计算

## 用户长期偏好

初始化、每日快照生成允许较慢；打开报表与筛选响应优先。已写入根 AGENTS.md 的 Persistent reporting preference。

## 已部署实现（2026-09-15）

- V1.2 按 dt、城市持久保存汇总，不保存 DUID 明细。
- 保存全部有订单、1–10 笔、超过10笔的价敏等级分布；城市分组之和须与独立 COUNT_DISTINCT 总人数一致。
- 每日完整结果一次 UPSERT 发布；失败不覆盖既有成功日。缺失字段、重复分页、非法计数拒绝发布。
- 启动补历史、每天10点刷新最新日、手动刷新31天；任务之间串行，单个任务最多2个日期并行、日期内查询串行，刷新不被启动补历史吞掉。
- 查询从持久快照/进程内缓存读取；订单档位和等级切换用前端已返回的 order_groups，不调用上游。
- 每个快照保留查询执行ID、请求、SQL和图表绑定；管理员核验重跑仍需白名单验证。
