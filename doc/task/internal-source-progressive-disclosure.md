# 内部资料源渐进式披露

## 目标

Agent 遇到内部问题缺少线索时，先看到一个简短资料源入口，再按需展开某个来源的指南，不把所有资料与操作细节塞进初始上下文。

## 本期范围

- 初始上下文只提示 `discover_internal_sources` 和 `get_internal_source_guide`。
- 所有现有 Agent 可发现这两个只读 MCP 工具。
- 来源摘要与单来源指南分两次返回；未知来源报错。
- Cooper、GitLab、数据地图、Agent 侧 Hive 当前均显示未接入，不提供伪造的检索结果。

## 验收

- Go 配置/工具规格测试及 daemon MCP 测试通过。
- 真实资料查询能力不作为本期验收；后续接入需按当前提问者逐次鉴权。

## 发布状态

本地实现与测试已完成；服务器发布待核对线上代码和访问权限，不能将工作区其他未提交改动一并部署。
