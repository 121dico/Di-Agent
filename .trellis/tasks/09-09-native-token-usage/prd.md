# 原生 Token 统计

用户已授权依据 09-08 的官方源码研究实施并同步线上。实现层面的选择由研究与现有界面确定。

- daemon 捕获 Codex app-server / exec 和 Claude stream-json 原生 usage；输入统一含缓存，缓存和 reasoning 为细分项不重复求和。
- 每个派发独立累计，重复累计快照覆盖；Codex新建thread可用原生total差值计算当前派发，Claude用result主循环本轮usage。容量仅取运行器报告，缺失不猜。
- 当前上下文使用最近一次模型请求的快照，与本轮和会话累计分开。压缩使当前上下文失效，直到新usage；历史累计不减少。
- 最终usage随task.complete可靠传输，流式usage进入独立metadata block供执行链路查看，正文不插统计文字。
- 后端以task ID幂等保存计量，最新上下文与跨代累计从原生记录读取；旧字符估算不算进真实账本。无原生数据只展示估算输入与未上报，不造窗口百分比。
- UI保持既有上下文页脚、详情抽屉、执行链路抽屉，在这些位置分别显示上下文、累计和本轮统计及来源。无需另开视觉设计。
- 验证边界：CLI公开事件解析、后端RecordDispatch/GetUsage、前端用户可见状态；检查10K→12K输入累计22K而当前12K、重复上报、缓存子集、空容量、压缩、刷新持久性。
- 完成条件：针对性回归、全套测试/类型检查、双轴review、真实页面真实CLI验收、发布双仓price_sensitive和线上备份部署。

## UI brief / gates

保留当前Ant Design抽屉、应用文字/边框语义变量与轨迹配色。统计区域使用轻量分隔线、tabular数字、16px间隔，无新动效或依赖。主入口保持上下文页脚→详情；回复→执行链路→本轮统计。unknown显示未上报，partial标记部分数据，缓存0显示0。窄屏数据网格两列。已由用户授权方案和现有界面确定，无待决视觉偏好。Gate0–7按现有证据auto-approved，Gate8–9等待真实页面验收与部署。
