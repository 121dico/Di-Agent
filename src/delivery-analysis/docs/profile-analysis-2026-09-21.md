# 基本画像与维度分布完整交互

## 对照 Demo 的功能

- 配置画像维度：多选、至少保留一项、当前会话按任务记忆；保留独立分日维度入口。
- 单维：饼图、条形图、精确人数与占比表；图例鼠标/键盘高亮、点击/Enter 打开拆分选择。
- 交叉：+依次选择二级与三级维度，不允许重复或超过三级；显示完整路径，支持重置。默认交叉矩阵，也可切条形图和长表。
- 自然语言：识别现有维度名称及常用别名；“再看看城市分框和战区”补充维度；“生命周期 × 充电频次 × 城市”执行联合拆分。不是任意文本的AI语义推理，未识别或超过三级时明确反馈。
- 原颜色/布局/弹窗保留，矩阵设可读列宽并横向滚动，列表高基数时滚动；失败清空统计、禁用依赖数据的入口。

## 统计与数据边界

server/profile.mjs 在后台从同快照联合分组获取 COUNT_DISTINCT(duid)，校验每桶 COUNT=COUNT_DISTINCT，并按日期、组别、全部维度逐桶与原单维分布对账。任何不一致阻止新快照发布。只持久化聚合，不返回或保存DUID明细。

召回使用所选 entry_dt 与 group_type 的当前标签；安心充使用 audience 最新分区，与效果统计选日独立。联合路径最多三级，返回该路径聚合，不向浏览器下发完整高维桶。整体占比=该组合人数/当前范围总人数；父级占比=该组合人数/前 n-1 级组合人数。零父级显示—，合法空桶为0。不使用 Demo 的单维边际比例相乘。

七个基础画像维度支持任意二/三级组合；召回另含流失周期。安心充额外购买状态、首末单日期、城市ID等继续提供单维查询，完整联合集合明确通过 profileCrossDimensions 声明。画像均为当前来源标签，不能冒充投放前基线。

加载接口只查询已发布快照；后台以枚举数量多的分组键优先，减少上游多列分页的递归分片次数。历史快照缺联合桶时显示准备中，不回填猜测值。
