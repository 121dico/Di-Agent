# 投放分析真实数据工作台

Node.js 22+，无运行时第三方依赖。使用既有 DiAgent 同源代理（8080 → 127.0.0.1:4173）。

## 运行

- `DI_AGENT_URL`：DiAgent 后端，默认 `http://127.0.0.1:8080`。
- `DI_AGENT_TOKEN_FILE`：既有服务凭据文件，默认 `runtime/service-token`。权限 0600，仅服务器保存，禁止提交。
- `DELIVERY_RUNTIME_DIR`：聚合快照目录，默认 `runtime`。
- `PORT` 默认 4173，`HOST` 默认 127.0.0.1。
- `npm start`；`npm test`；`npm run check`。

启动时读取持久快照，后台立即准备数据并每 30 分钟刷新。准备完成、粒度及维度合计验证通过后原子替换；失败保留旧快照并返回状态。浏览器筛选只读聚合结果，不查询上游，不保存用户明细。

`GET /api/bootstrap?taskId=coupon|effect&date=YYYY-MM-DD&group=...&dimension=...&cumulativeGroup=...&cumulativeDimension=...`：需要现有 DiAgent Bearer JWT，未知任务或无效筛选拒绝。`GET /healthz` 可查看 ready 状态，不返回数据或凭据。

## 数据口径

发券后复购率 = 同一进组日已领券且复购人数 / 领券人数；整体复购率另以入组人数为分母。日期窗口沿用源表 D+1–D+7。城市使用源表高频城市；画像不可当作投放前快照。
安心充比例 = 安心充近 30 天订单合计 / 充电近 30 天订单合计；不得跨日加和。个人达标依据源表标记，与整体比例的目标判定分开。
