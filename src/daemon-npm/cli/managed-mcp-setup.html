1准备公司身份

启动滴滴安全助手，登录本人账号，在「智能体安全」确认防护开启。检测失败时请同时核对新 API Key；此处不会代你登录或输入 D 盾。

安装安全助手 ↗身份配置指南 ↗
2填写个人 API Key

在 MCP Hub 的「访问令牌」创建新版 Key，按公司流程完成验证后复制。不要使用他人的 Key。

创建 API Key ↗

macOS 保存到钥匙串；Linux 保存到仅本人可读的文件。原值不会回填。Windows 暂不支持页面保存。

3确认数梦项目

打开数梦项目设置，复制「项目 Code」。它不是数字 projectId（例如 839），也不一定与数据库名称相同。

打开数梦 ↗在哪里找项目 Code ↗

保存不会自动申请项目或数据权限；真实查询仍由数梦鉴权。

此设备暂不支持页面保存个人凭据

Windows 请勿在本页粘贴 Key。请在本人电脑的用户环境变量中设置：

  • DI_AGENT_DATADREAM_API_KEY本人新版 API Key，不含 Bearer
  • DI_AGENT_DATADREAM_PROJECT_CODE数梦项目 Code，不是数字 ID

可从 Windows 搜索「编辑账户的环境变量」进入，仅配置本人用户变量，不配置系统共享变量。环境变量仍是敏感信息，请勿截图、分享或写进项目文件。等运行中的 Agent 任务结束，再退出并重新启动 Di Agent 连接程序，使新进程读取变量，然后回平台重新检测。

完成后返回 Di Agent，点击「检查连接」刷新状态。本配置页 15 分钟后失效；刷新后需从平台重新打开。
