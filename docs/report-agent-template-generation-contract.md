# 报表 Agent 默认模板：V1.2 基础图表

`template-1`（版本 `1.0.0`）固定现有 V1.2 报表的**视觉语法**，而不是固定价敏业务内容。任何数据源生成报表时，曲线、柱状图和饼/环图直接调用 V1.2 的 `SmoothChart`、`IncrementBarChart`、`DonutChart` 和相同 CSS。颜色、几何、坐标轴、网格、图例、悬停、动画、卡片与响应式由程序控制；Agent 不能传 HTML、CSS、任意颜色或自制图表。

Agent 可根据真实数据决定清洗与计算、指标、图表类型、字段映射、标题、板块顺序和相邻图表组合。时间或有序维度使用 `line`，单值类别比较使用 `bar`，同一统计范围的非负类别占比使用 `donut`，精确记录使用 `table`。价敏专有板块只适用于有相应真实语义的数据源；普通内容不复制 V1.2 的业务导航和分析结论。

## 连接的 Codex 工作流

1. `discover_report_data` 查看可用数据源、字段类型与操作能力。
2. `get_report_template` 读取默认模板 ID、版本、支持图形、字段绑定和锁定的视觉规则。
3. `query_report_data` 按真实字段执行查询。每个图必须绑定本轮查询的完整 `query_id`；不能把未取完的分页结果画成整体分布。价敏 V1.2 亿级源可使用 `prepared_view=v12_dashboard`，避免实时全表去重导致 ClickHouse 内存超限。
4. `save_personal_report` 提交 `template_id=template-1`、板块和字段绑定。服务端按当前用户的查询凭证填入真实行、验证数值和模板版本，剥离模型传入的颜色，前端以固定组件渲染。

保存实例的模板版本冻结为 `1.0.0`。现有 V1.2 预计算快照以唯一 `v12_dashboard` 板块复用其指标、分布和趋势；其他数据源用通用指标、图表和表格板块。后续模板应注册新 ID/版本，并由用户显式选择，不能静默改动已保存实例。

## 视觉验收

- 同一数据分别由不同模型生成：只要图表类型与字段绑定相同，曲线、柱状图和饼/环图使用同一组件与样式；模型生成的颜色不会生效。
- 用非价敏数据生成三个图：标题、值、类别和口径随数据改变，曲线高度、柱形几何、环形半径/线宽、调色板、图例、交互和响应式保持 V1.2 模板形态。不得出现“价敏用户”这类错误业务文案。
- 改动数据源数值再生成：图表值随真实查询改变，模板样式不变；查询失败或字段无效时不保存伪造报表。

当前限制：模板支持最多 16 个板块，单图查询最多取完整的 100 行结果；复杂跨源加工、用户配置第二套模板和旧实例的模板迁移仍未实现。
