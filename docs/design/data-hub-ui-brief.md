# 数据接入台 UI Brief（2026-10-08）

## 设计与范围

面向需要确认数据可用性并发起查询的 Di Agent 用户，把原“数据”页改为日常使用的连接工作台。用户确认：API、Hadoop/Hive、数据地图和 Cooper 直接列在左侧；去掉“新建知识库”及其空态。保留原 API 数据源管理弹窗作为二级操作。数据地图与 Cooper 缺少服务端接入时必须显示“未接入”，不能用浏览器登录状态冒充连接成功。

## 信息层级与路径

左侧：数据连接及状态点；选中 Hive 后显示已批准表。右侧：当前连接账号、连接状态、解释；Hive 为 SQL 编辑、运行并保存、查询结果、历史；API 为脱敏 AppKey 及配置状态、管理入口；未接入系统为明确说明。刷新按钮重新检查连接。

Hive 路径：进入“数据” → 选 Hadoop / Hive → 选表 → 编辑 SQL → 运行并保存 → 查看结果 → 从历史重开。失败可修改 SQL 或检查连接重试。非授权用户显示权限错误与重试入口；没有伪造的成功态。

## 视觉与组件

参考 1：用户所附旧“数据”面板，只沿用左侧数据入口和产品现有字号，不保留知识库空态。参考 2：现有报表数据源管理弹窗，沿用 Ant Design 表单、按钮和标签；避免增加新组件库。全局导航保留现有 Di Agent 视觉语言。

桌面为左侧连接栏 + 右侧工作区；右侧按标题、连接状态、查询、记录排序。语义 token：应用灰白画布、白色表面、主文本 `--color-text`、次文本 `--color-text-secondary`、边框 `--color-border-light`、主色 `--color-primary`；绿色仅表示已连接，灰色表示未接入，红色表示失败。SQL/表名采用等宽字体。卡片边界只用于状态和独立工作块。手机宽度默认收起全局导航，接入栏置顶并可滚动，正文纵向排列。

状态：加载 Spinner；空查询历史 Empty；未配置、连接失败、需管理员权限、未接入分别用文字说明；执行中按钮 loading；保存成功后显示记录 ID、行数、耗时和时间；超限/查询错误显示服务端信息。按钮与列表项使用原生可聚焦元素。无自动动效；尊重现有全局 reduced-motion 处理。

真实产品验收仍需：启动目标应用，使用绑定的 Di Agent 账号从全局“数据”入口进入，选表并执行实际聚合 SQL，打开记录，刷新后确认结果仍在。当前最后一个已完成的真实服务步骤是通过同一 Go Hive 驱动对两张表的带分区只读查询；页面与数据库持久化的端到端路径尚未验证。
