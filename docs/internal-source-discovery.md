# 内部资料源渐进发现（第一版）

Agent 的初始上下文只包含 `discover_internal_sources` 与 `get_internal_source_guide` 两个入口，不预载来源指南。遇到内部资料缺口时，Agent 可先发现 Cooper、GitLab、数据地图、Hive 的简短用途与接入状态，再按问题线索展开单一来源。没有固定的查找顺序。

这两个 MCP 工具当前只返回非敏感元数据，所有 Agent 均可调用。它们**不会搜索文档、代码或数据**，也不会读取用户凭据。四个来源在 Agent 侧均标记为 `not_connected`；其中 Hive 页面现有的单用户连接，不等于可代表任意提问者执行查询。Agent 应明确说明未接入，不能把指南当成真实检索结果。

后续每接入一个来源，都需要独立实现按当前提问者授权的只读连接器，并让该来源的目录状态与实际能力同步。查询宜先返回有界摘要，再由 Agent 按需打开原文或结果；每次读取仍需校验用户权限并保留出处。
